# 작업 복습 작성 틀

작업 단계 중 허용된 학습을 위한 자료다. 실제 출제 문항이 아니며 AI 사용이 금지된
후속 평가 단계에서 사용하지 않는다. 가상 예시와 실제 수행을 섞지 않는다.

## 핵심 동작

입력 → 중요한 처리/결정 → 출력/상태 변화를 자신의 말로 설명할 수 있게 적는다.
필수 조건 중 구현됨/검증됨/사용자 확인됨/미완료를 구분한다.

## 중요한 결정과 실제 확인

| 결정/수정 | 이유 | 근거 | 행위 주체 |
|---|---|---|---|
| 실제 기록에서 추출 | 실제 이유 | 파일/명령/결과 | agent 실행 / user 직접 확인 / user 결정 |

## 예상 질문 카드

- 질문:
- 핵심 답변 3–5문장:
- 근거 파일/실행 결과:
- 이어질 수 있는 질문:
- 아직 말하면 안 되는 미확인 주장:

권장 후보: 핵심 기능과 확인법, AI 제안 중 확인/수정한 것, 선택의 이유,
경계 입력, 실제 실패 원인, 시간 우선순위, 남은 한계. 실제 기록이 풍부한 5–8개를
선택하고 모든 항목을 억지로 채우지 않는다.

## 직접 이해 확인

허용된 작업 시간에 작은 입력을 바꾸고 결과를 예측한 뒤 직접 확인해 본다.
사용자가 실행하지 않았다면 “직접 확인했다”고 적지 않는다. 빈 증거는 빈 증거다.
