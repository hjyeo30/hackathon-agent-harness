# 독립 검토 기록

- 모드: 계획 / 코드 / 실제 실행 / recap 근거
- 대상 요구사항 및 코드 상태:
- 검토한 자료와 실제 실행한 명령:
- 판정: APPROVE / CHANGES NEEDED / INCONCLUSIVE

## 발견 사항

각 지적은 다음을 포함한다. 지적이 없으면 없다고 적는다.

- 중요도: 반드시 수정 / 선택 개선
- 요구사항 및 위치:
- 구체적인 실패 조건:
- 기대 결과 / 관찰 결과:
- 재현 명령과 evidence:
- 실제 영향:
- 가장 작은 수정:
- 분류: 제품 결함 / 검증 결함 / 환경 문제

## 관측과 검증 공백

같은 코드/입력/인스턴스의 증거인지, 필수 검사 누락·0개검사·skip·약화한 assert가
있는지, 로그·메트릭·트레이스로 원인이 충분히 좁혀지는지 적는다.
정적 코드 읽기와 실제 실행을 분리한다. 기존 PASS를 보았다는 것은 재실행이 아니다.

## 지적 처리

| 지적 | 처리 | 이유 | 재검증 증거 |
|---|---|---|---|
| 실제 ID | 수정 / 기각 / 보류 | 근거 | 실행 경로 |

미래의 일반적인 보안·확장성·스타일 제안은 현재 필수 동작을 위반하지 않는 한
완료를 막지 않는다. 과잉 구현도 구체적인 비용/오류와 연결해 설명한다.
