# 에이전트 인계

## 위임할 때

- 목표와 요구사항 ID:
- 원문 요구사항/계획/현재 코드 위치:
- 결정된 업무 의미와 아직 결정되지 않은 것:
- 수정 가능한 파일/경계:
- 런타임 소유권: 서버, 포트, 데이터 디렉터리, 브라우저 세션
- 핵심 입력과 독립 기대 결과:
- 필요한 관측: 로그/메트릭/트레이스 중 실패 원인을 가를 정보
- 반환 조건과 중단 조건:
- 외부 변경/커밋/공개 권한: 있으면 정확한 범위, 없으면 없음

## 구현자가 반환할 때

- 구현한 행동과 요구사항:
- 변경 파일:
- 시작/재현/검증 명령:
- 실제 기대값과 관찰값:
- run ID와 evidence 경로:
- 알려진 실패, 미실행 검사, 환경 제약:
- 계획과 달라진 점 및 이유:
- 사용자에게 보여줄 최소 조작:

## 짧은 위임 예시

“R1 수율 집계를 구현한다. 결정: 전체 양품/전체 검사 수, 분모 0은 명시적 오류.
parser.py와 API handler만 수정한다. UI는 아직 소유하지 않는다. (9,10),(1,90)의
정답 0.1을 검사하고 input_rows/invalid_rows 및 parse→aggregate 단계 시간을 남긴다.
빈 입력 정책이 코드에서 다르면 임의 변경하지 말고 보고한다.”

검토자는 위임 원문과 계획을 먼저 받고 구현자 요약은 그다음에 읽는다.
