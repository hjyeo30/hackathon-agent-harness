# 선택형 설정

`mcp/*.toml`은 부모 Codex 설정에 필요한 항목만 병합하는 예시입니다.
bootstrap은 기존 config를 덮어쓰지 않으며 이 서버들을 자동 활성화하지 않습니다.
동일한 서버가 이미 있는지, 설치와 외부 통신이 허용되는지 먼저 확인하세요.
연결 성공 후 실제 로컬 앱을 한 번 조작해야 실행 확인 상태로 올릴 수 있습니다.

모델은 부모의 허용된 설정을 상속합니다. 계정별 모델명을 추측하거나 제한 모델을
고정하지 않습니다. 서브에이전트의 역할 지침은 독립 sandbox 보장이 아닙니다.
