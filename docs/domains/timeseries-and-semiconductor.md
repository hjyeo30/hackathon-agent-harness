# 시계열·설비·반도체 품질 시나리오

이 문서는 연습 시나리오이며 실제 출제를 예측하지 않는다. 공정 원인 판단과 단순 이상
신호를 구분한다. 관리 한계와 제품 규격 한계도 같은 개념으로 쓰지 않는다.

## 먼저 확인

사건 시각/수신 시각, 시간대, 샘플 간격, 설비·센서 ID, 단위, 정상 운전 구간,
정비/시작/종료 상태, 결측/센서 포화/고착의 의미를 확인한다.
정렬·중복·늦은 이벤트를 어떻게 처리할지 정하고 미래 데이터를 기준선에 넣지 않는다.

## 작은 시나리오

| 시나리오 | 왜 필요한가 | 판정 |
|---|---|---|
| 정상 일정 범위 | 오경보 기준선 | 불필요한 경보 수 |
| 단일 급변 | spike 반응 | 주입 위치와 탐지 지연 |
| 점진적 변화 | 드리프트 | 설정된 탐지 정의와 범위 |
| 센서 고착 | 변동 0의 의미 | 정상 일정값과 구분 가능한 업무 근거 |
| 결측 구간 | 없는 값을 정상으로 해석 | 결측 상태가 노출됨 |
| 역순/중복 시각 | 처리 순서/중복 정책 | 명시적 정렬/거절/중복 처리 |

threshold 바로 아래·같음·위와 window 길이보다 짧은 입력을 확인한다. 합성 급변을
찾았다고 실제 고장을 예측한다고 주장하지 않는다. false positive/negative의 비용과
레이블 가용성에 따라 적절한 기준선을 선택한다.

## 관측과 사용자 확인

read→time alignment→baseline→score→alarm 단계, timestamp 범위, 결측·중복 수,
경보 수·탐지 지연, 파라미터/기준선 구간을 기록한다. 그래프에는 원신호·기준선·
경보 시점·결측 구간을 같이 보여 원자료와 출력이 일치하는지 확인한다.
실제 공정 조치는 승인된 담당자의 판단 영역이며 분석 결과의 한계를 설명한다.

웨이퍼 패턴은 [이미지](images.md), 수율 집계는 [데이터](data-and-sql.md),
학습 기반 이상 탐지는 [ML](ml.md)을 필요한 만큼 함께 읽는다.
