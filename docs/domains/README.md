# 분야별 선택 읽기

현재 과제의 경계를 다루는 문서만 읽는다. 이 목록은 예상 출제 유형을 단정하지 않는다.
실행 예제는 저장소의 `examples/` 색인에서 고르고 실제 문제의 조건을 덮어쓰지 않는다.

| 상황 | 참고 | 먼저 확인할 것 |
|---|---|---|
| 웹/대시보드 | [web](web.md) | 사용자 흐름·상태·API·화면·파일 |
| API/로그인/외부 호출 | [api-and-auth](api-and-auth.md) | 권한·계약·부작용·재시도 |
| CSV/SQL/보고서 | [data-and-sql](data-and-sql.md) | 의미·키·단위·집계·손계산 |
| 이미지/검사 패턴 | [images](images.md) | 좌표·채널·연결·전처리·레이블 |
| ML 예측 | [ml](ml.md) | 분할·누수·기준선·오류 비용 |
| 센서/반도체 공정 | [timeseries-and-semiconductor](timeseries-and-semiconductor.md) | 시간·결측·정상/고착/드리프트 |
| 큰 파일/속도 | [large-data](large-data.md) | 중간 메모리·분할 가능성·실측 |
| RAG/업무 Agent | [rag-and-agents](rag-and-agents.md) | 근거·도구 부작용·중복·종료 |
| 일정/배치 | [optimization](optimization.md) | hard constraints·feasibility·기준선 |
| 모바일/CLI | [mobile-and-cli](mobile-and-cli.md) | 실제 실행 표면과 도구 가용성 |

관측과 검증 원칙은 각각 [observability](../guides/observability.md),
[testing](../guides/testing.md)에 있다. 언어 경계는 [Python](../languages/python.md),
[TypeScript](../languages/typescript.md)에서 해당 부분만 읽는다.
