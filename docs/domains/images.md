# 이미지 분석과 결함 패턴

## 먼저 정의할 것

문제가 분류/검출/분할/계수 중 무엇인지, 출력 좌표/면적의 단위와 판정 기준을 정한다.
입력 dimensions, 채널 순서, bit depth, 값 범위, 회전/방향, 리사이즈 정책을 확인한다.
모델이 필요한지 단순 규칙으로 요구를 만족하는지 작은 기준선을 비교한다.

“연결된 결함”의 정의도 업무 결정이다. 다음 두 픽셀은 상하좌우 연결이면 2개,
대각선도 연결하면 1개다.

```text
0 1 0
1 0 0
0 0 0
```

## 입력 설계

| 입력 | 발견할 실패 | 기대값 근거 |
|---|---|---|
| 비정사각형 | width/height 또는 x/y 교환 | 직접 지정한 좌표 |
| 가장자리의 1픽셀 | 경계 누락 | 알려진 위치/면적 |
| 대각선 두 픽셀 | 연결 정의 혼동 | 선택한 4/8 연결 |
| 빈 이미지/전부 결함 | 0개·최대 영역 처리 | 알려진 count/area |
| 임계값 아래/같음/위 | >와 >= 오류 | 합의한 임계 규칙 |
| 손상/지원 밖 입력 | decoder 오류 은폐 | 명시적인 오류 |

리사이즈했다면 좌표를 원본으로 되돌리는 기준을 검사한다. 예측 overlay를 원본에 그려
실제 위치를 확인한다. 비주얼 확인만으로 정확도를 주장하지 않고 레이블/정답과 비교한다.
반대로 수치 테스트 통과만으로 overlay의 축·비율·표시를 확인했다고 말하지 않는다.

## 변형과 한계

회전/밝기 변경이 결과를 보존해야 하는지는 도메인 의미에 달려 있다. 모든 불량 패턴에
회전 불변을 강제하지 않는다. 합성 패턴 통과는 전처리/계수 로직의 증거이며 실 제조
데이터 성능을 증명하지 않는다. 공정 원인은 패턴 모양만으로 단정하지 않는다.

## 관측

decode→transform→detect→measure→overlay span, 입력 크기/채널/transform 설정,
검출 수·면적·경과 시간을 남긴다. 과제 이미지 원본을 외부로 전송하지 않는다.
모델 학습을 한다면 [ML](ml.md)의 분할·누수·기준선도 확인한다.
