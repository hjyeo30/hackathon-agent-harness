# 시험 환경에 맞춰 사용하는 방법

이 문서는 공개 준비용 운영 메모이며 공식 규정을 대체하지 않습니다.
원본 안내문·실제 문제·답안을 포함하지 않습니다. 당일 README와 운영 안내를 우선합니다.

사용자는 실제 환경에서 Codex CLI, 서브에이전트, Browser, MCP 사용을 확인했습니다.
각 외부 도구의 패키지·브라우저 바이너리·버전·캡처 허용까지 확인했다는 뜻은 아닙니다.
`doctor`의 버전 확인도 실제 사용자 흐름 검증과 다릅니다.

## 180분 운영 예시

| 시간 | 결과 |
|---|---|
| 0~20분 | 요구사항·제출물·환경·중요한 업무 질문 |
| 20~35분 | 최소 흐름·정답 기준·계획 합의 |
| 35~85분 | 첫 동작 완성·검토·메인 직접 사용·사용자 확인 |
| 85~135분 | 나머지 필수 조건과 중요한 실패 처리 |
| 135~165분 | 영향받는 회귀·경계 검증, 설명과 실제 코드 일치 |
| 165~180분 | 범위 확장 중단, 필수 경로·저장·제출 확인 |

고정 스케줄이 아닙니다. AI 대기와 사용자 확인 시간도 포함합니다.
마지막에 도구 설치나 구조 변경을 시작하지 않습니다.

## 공개 준비 자료와 실제 작업 자료

공개 GitHub의 일반 준비 자료를 가져오는 것과 실제 문제·파일·작업 결과를
외부로 보내는 것은 다릅니다. 후자는 금지된 환경을 전제로 합니다.
이 kit를 실제 답안 저장소로 사용하거나 공개 Issues에 문제를 올리지 않습니다.
실전 기록은 제공된 작업 환경 내부의 `issues/`와 `.harness/runs/` 등에 둡니다.
개인 키·개인 비공개 자료·원격 개인 서버를 실전에 연결하는 절차를 제공하지 않습니다.

## 도구 조건

제공된 모델 목록에서 선택합니다. 제한된 모델을 설정 파일에 고정하지 않습니다.
브라우저는 실행 서버의 실제 포트와 경로를 확인하고, 미리보기 요구에 따라
`0.0.0.0` 바인딩을 사용합니다. 로컬 개발 예제는 기본 loopback으로 시작할 수 있습니다.
이미 제공된 MCP를 우선 살피고, 추가 설치는 필요한 기능에만 한정합니다.
자동 스크린샷·영상·트레이스와 외부 통신은 실제 허용 조건을 확인합니다.
도구가 막히면 제한 우회나 운영 프로세스 종료 대신 공식 도움/신고 경로를 사용합니다.

## 종료와 설명

제출 전 필수 파일·실행 상태·저장·검증되지 않은 조건을 확인합니다.
recap은 실제 판단과 검증을 자기 말로 설명하는 연습입니다.
후속 서술형에서 AI 사용이 금지되면 그 단계에서는 이 스킬도 사용하지 않습니다.
예상 질문은 학습용이며 실제 출제 예측이나 공식 배점표가 아닙니다.
