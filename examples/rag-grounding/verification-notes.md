# 독립 검토 발견 기록 — 2026-10-31

독립 검토 에이전트가 인용 검증기 자체의 false positive를 발견했다. `answer=null`,
빈 인용 객체 또는 존재하지 않는 문서의 `quote=null`이 `.get()`에서 반환된 `None`과
같아 근거가 있다고 판정되었다. 이는 실제 문서에 대한 membership 확인 없이 값만
비교한 결함이다. 응답과 인용의 구조·타입을 확인하고, 문서 식별자가 현재 문서 목록에
실제로 있는지 확인한 뒤 원문·인용·답변이 같은지 비교하도록 바꿨다.

다른 결함은 동일 id/version의 상충 문서가 최신 버전 뒤에 오면 감지되지 않는 것이었다.
최신 문서만 보관하던 로직에 모든 `(id, version)` 쌍을 검사하는 별도 map을 추가했다.
v1 두 개와 v2의 가능한 순서 여섯 가지 모두 오류를 내도록 회귀 검사했다.

먼저 회귀 검사를 추가한 상태에서 9개 검사가 실행되고 6개 subtest 실패를 확인했다.
수정 후 잘못된 문서 구조까지 포함한 10개 검사가 통과했다. 이 기록은 에이전트 검토와
실행 결과이며 사용자가 직접 발견하거나 승인한 것으로 표현하지 않는다. 원문 일치가
문서 자체의 진실성, 질문 적합성 또는 실제 LLM의 grounding을 보장하지는 않는다.
