# Recap actual work

## Timing and scope

Use on recap/복습/예상 질문/내가 설명할 수 있게 requests. This is preparation during
the permitted work phase. Do not provide AI assistance during an assessment phase that
forbids AI. Do not claim to know future exam questions.
A recap request does not authorize new implementation or silently running a full suite.

## Evidence first

Read original requirements, accepted plan, progress/decision records, current source,
verification evidence and user feedback. Use [recap guide](../../../docs/guides/recap.md)
and [template](../../../templates/recap.md). Resolve cited paths before presenting them.
Explain core input → processing → output and why it addresses the requirement.
Prioritize actual difficult decisions, AI proposals challenged, errors reproduced,
meaningful boundary tests, and remaining limitations.

Keep these actors separate:
- agent executed a check;
- user read the agent's report;
- user directly operated the result;
- user chose or revised a policy.
Only attribute a human action when conversation or task records establish it.
If a required fact is missing, state the gap. Suggest a small direct exercise during the
permitted work phase; do not fill it with a plausible fictional experience.

## Practice output

For a narrow recap question, answer it directly and concisely. Add question cards
when requested or useful; do not manufacture extra topics to reach a count.
Select usually 5–8 questions based on actual work, not a fixed exhaustive questionnaire.
For each: question, 3–5 sentence factual answer, evidence location, likely follow-up,
and a claim to avoid because it is unverified. Offer deeper explanation when requested.
Suitable themes are core behavior and verification, AI suggestions checked/modified,
tradeoffs, non-normal inputs, an actual bug, scope priorities, and remaining limits.
Mark any illustrative answer as hypothetical, not as the user's accomplishment.

## Completion

Separate confirmed facts, informed interpretations, unverified areas, and future ideas.
A user should be able to explain the result in their own words from this recap.
Do not write a polished first-person account claiming they performed agent actions.
Do not rewrite the original plan or decision history to make the outcome look inevitable.
